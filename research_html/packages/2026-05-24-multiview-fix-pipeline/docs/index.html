View Diversification — training-signal driven 2026-05-24

Three mechanisms (soft-weighted CE, inter-slot orthogonality regularizer, per-slot k-means init) make 4 slots learn distinct views without partitioning the shared 4096 codebook.

training fix view-diversification orthogonality kmeans-init
preview · Open full →

P3 alone supervises all N slots but does not guarantee they learn different things; the optimizer can collapse all N MLPs to the same function. This fix adds three training-signal mechanisms without partitioning the codebook: (a) caption-conditioned soft-weighted CE via token_idx, (b) inter-slot orthogonality regularizer, (c) per-slot k-means init at step 0 only. The 4096 codebook stays shared — same view content keeps mapping to same centroid. Bundled with P3 in F2; S cell ablates each mechanism independently.
