View Diversification — training-signal driven 2026-05-24

Three mechanisms (soft-weighted CE, inter-slot orthogonality regularizer, per-slot k-means init) make 4 slots learn distinct views without partitioning the shared 4096 codebook.

training fix view-diversification orthogonality kmeans-init
preview · Open full →

P3 alone supervises all N slots but does not guarantee they learn different things; the optimizer can collapse all N MLPs to the same function. This fix adds three training-signal mechanisms without partitioning the codebook: (a) caption-conditioned soft-weighted CE via token_idx, (b) inter-slot orthogonality regularizer, (c) per-slot k-means init at step 0 only. The 4096 codebook stays shared — same view content keeps mapping to same centroid. Bundled with P3 in F2; S cell ablates each mechanism independently.

K-means Inheritance Fix — loop-boundary codebook seed sees all N slots 2026-05-24

Flips do_epoch_encode to dedup-by-video + return_all=True so the faiss-GPU k-means at every loop boundary sees explicit per-slot signal — not the select(token_idx)-reduced subset. Stacked on F2 in cell K1.

training fix codebook-seed kmeans dedup-by-video
preview · Open full →

The select(token_idx) reduction at models/grdr.py:209-211 has two downstream consequences. F2's bundle addresses consequence A (train-step CE only supervises one slot). Consequence B is still live: do_epoch_encode at every loop boundary also goes through the same select-reduced path when seeding the next loop's codebook. K1 carries explicit per-slot signal into the codebook seed by switching our_encode_dual to dedup-by-video + return_all=True; faiss-GPU k-means then runs on [num_videos × N, D] instead of [num_text_samples, D]. Memory peak drops 22 GB → 17.6 GB; encoder forward calls drop 5× (per-video instead of per-text). H3 gate = K1 > F2 by ≥ 1.0 CanHit@100 pp at 500K.
