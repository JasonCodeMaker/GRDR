Fix P3 — All-slot CE supervision foundation fix

Remove select(token_idx) from the train_step; supervise every slot of the multi-view encoder under CE/code loss. The only fix that addresses the foundation cause directly. P3 is the backbone of F2 — it is never run standalone (the F1 "P3 alone" cell was dropped because the 4 MLPs predictably collapse to the same function without view-diversification constraints).

Open · cells: F2 (bundled with view diversification) · 2026-05-24

View diversification secondary fix

Make the 4 slots learn distinct views via three training-signal mechanisms: (a) caption-conditioned soft-weighted CE via token_idx, (b) inter-slot orthogonality regularizer, (c) per-slot k-means init at step 0 only. The 4096 codebook stays shared — same view content keeps mapping to same centroid. Bundled with P3 in F2.

Open · cells: F2 · 2026-05-24

Fix P1 — Shared token_idx across pseudo siblings control

Cheap-fix control variant: pseudo siblings inherit real-caption token_idx. Predicted to underperform P3 because it leaves the foundation cause intact. Run as the H3-falsification cell; without it, a reviewer can ask "did you actually need the foundation fix?"
