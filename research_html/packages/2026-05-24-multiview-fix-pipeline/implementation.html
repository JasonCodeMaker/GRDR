Algorithm changes (T14)

P3: all-slot CE supervision (the foundation fix)

Code anchor
models/grdr.py:_forward_video + trainer/trainer.py:train_step
Description
Replace select(token_idx) reduction in _forward_video with an all_slots branch that returns full [B, N, D] continuous_embeds + [B, N] indices. In train_step, when the flag is on, compute one CE per slot (4× CE summed) against each slot's own code target; one code_loss per slot summed. The query head still produces a single query_prob; the matching question is "does query predict each slot's code" — option A is N separate CE losses; option B is logsumexp-marginalized CE. Default to A; B is a follow-up.
Expected sign
CanHit@100 ↑ (vs B3 reproducer when bundled into F2); H2 prediction = F2 > B1 (primary gate). H1 (loss-side necessity) supported by §2.5 + cross-dataset evidence; no F3 cell.
Magnitude band
F2 CanHit@100 > B1 + 1 pp if H2 holds; F2 < B1 if loss-side fix doesn't recover the gap at 500K (drop NLT=4 from production)
Validating exps
F2 (P3 + view div) vs B1 (primary gate); V at 2.15M vs production anchor 95.57. F1 (P3 alone) + F3 (P1 alone) cells both dropped — outcomes structurally predicted, no info value.

View diversification bundle (F2 only) — keeps shared codebook

Code anchor
trainer/trainer.py:train_step (mech a + b) + models/video_rqvae/vq.py:init_emb (mech c)
Description
Three training-signal mechanisms applied on top of P3 to make the 4 MLPs learn distinct views without partitioning the codebook. (a) soft-weighted CE via token_idx: per-row slot weights = 0.7 on token_idx-routed slot, 0.1/(N−1) on others (still all > 0 → no dormancy). (b) inter-slot orthogonality regularizer: w_ortho · mean(|cos(slot_i, slot_j)|) over off-diagonal pairs. (c) per-slot k-means init: at step 0 only, run N independent k-means (n_e/N centroids each) on per-slot encoder outputs and concatenate into the shared nn.Embedding(n_e, D); after init the codebook is fully shared and any slot can argmin to any centroid. Same view content → same code is preserved (semantic aggregation works correctly); view diversification comes from training signal, not from codebook partitioning.
Expected sign
CanHit@100 ↑ vs B1 baseline; H2 prediction = F2 > B1 (primary success gate). View-diversification diagnostics in healthy ranges: per-slot unique-code count > 500 (each), inter-slot mean cosine < 0.5, per-video sID multiplicity > 2.
Magnitude band
F2 ∈ [B1+1pp, B1+5pp] if H2 holds; F2 < B1 if NLT=4 cannot be recovered at this codebase + scale.
Validating exps
F2 vs B1 (primary gate); V at 2.15M vs production anchor 95.57 (H2-scale); S single-loop sweep ablates each of (a) soft-weighted CE / (b) slot_orthogonality_weight / (c) per_slot_init to confirm all three mechanisms carry weight.

K1: K-means inheritance fix (stacked on F2) — codebook seed sees all N slots

Code anchor
trainer/evaluator.py:our_encode_dual + trainer/evaluator.py:do_epoch_encode (reuses models/grdr.py:_forward_video return_all=True path)
Description
The select(token_idx) reduction at models/grdr.py:209-211 has two downstream consequences. F2 fixes consequence A (train-step CE only supervises one slot). Consequence B is still live: do_epoch_encode at every loop boundary also calls our_encode_dual with return_all=False, which goes through the same select reduction; the faiss-GPU k-means that seeds the next loop's codebook therefore sees only the token_idx-routed slot per text sample. K1 adds --codebook_seed_all_slots: switch the encode pass to dedup-by-video (per-video DataLoader sampler) + return_all=True (the same code path F2 already needs for all-slot CE). The collected features now have shape [num_videos × N, D]; faiss-GPU k-means runs on this explicit per-slot mixture. Memory peak drops from 22 GB → 17.6 GB at 2.15M scale; encoder forward calls drop 5× (per-video instead of per-text). Same shared 4096 codebook; only the seed input changes.
Expected sign
CanHit@100(K1) ↑ vs F2 alone at 500K if H3 holds; Kmeans balance diagnostic (printed inside do_epoch_encode) improves. K1 do_epoch_encode wall-clock ≤ F2 (dedup-by-video drops encoder calls 5×).
Magnitude band
K1 ∈ [F2+1pp, F2+3pp] if H3 holds; K1 ≤ F2+0.5 pp if F2's train-step bundle is sufficient on its own (consequence B implicitly absorbed by F2's view-diversification regularizer maintaining slot distinctness through training).
Validating exps
K1 vs F2 at 500K single-seed (primary H3 gate); V at 2.15M with the K1-vs-F2 winning recipe vs production anchor 95.57 (H2-scale).

Status
